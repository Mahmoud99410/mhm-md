✨ تحسين بواسطة Claude API (اختياري)

يعيد Claude ترتيب المستند كمواصفات مشروع واضحة (متطلبات، معايير قبول، مراحل) دون حذف أي معلومة. يحتاج مفتاح API من console.anthropic.com ويُحفظ على جهازك فقط. يستهلك توكنز مرة واحدة.

كيف تستخدمه مع Claude؟

  1. Claude العادي: ارفع ملف MD الناتج بدل الـPDF، أو اضغط «نسخ» والصقه في المحادثة.
  2. Claude Code: اضغط «📦 حزمة Claude Code» وفُك الـZIP داخل مجلد مشروعك. ستحصل على CLAUDE.md (يقرأه Claude Code تلقائياً في كل جلسة) ومجلد docs/ مقسّم حسب الأقسام مع فهرس INDEX.md، فيقرأ الجزء الذي يحتاجه فقط.
  3. رفع الـPDF مباشرة يكلّف تقريباً صورة لكل صفحة + النص، أما MD فهو نص فقط.
  4. راجع «تقرير الجودة» تحت كل ملف قبل الإرسال — يخبرك إن كانت صفحة بلا نص أو جدول يحتاج مراجعة.
